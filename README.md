# masa-open-space-landing-page

Landing page of Masa Open Space gym for Mitzpe Fomo and more.

## סיפורון — ניהול תלמידים ויצירת סיפורים

Help language teachers manage students and create personalized stories.

מערכת Web בעברית למורים לשפות. המורים מנהלים תלמידים, רמות ומילים שנלמדו, קובעים שעת סיפור יומית וצופים בהיסטוריה. מנהל המערכת מנהל חשבונות מורים וספקי AI. המערכת בנויה עם React, Node.js/Express ו־MySQL מקומי — **ללא Docker**.

### דרישות

- Node.js בגרסת LTS ו־npm.
- MySQL Server 8.0 וממשק ניהול כגון MySQL Workbench.

### הגדרת MySQL במחשב מקומי

1. התקינו והפעילו MySQL Server 8.0. התקינו את תלותי הפרויקט וצרו קובצי הגדרה עם סודות אקראיים מקומיים:

   ```powershell
   npm install
   npm run setup:local
   ```

2. פתחו את `database/local-setup.sql` ב־MySQL Workbench, התחברו לחשבון מנהל MySQL והריצו אותו. הקובץ יוצר מסד ומשתמש ייעודי עם הרשאות מוגבלות, הן עבור `localhost` והן עבור `127.0.0.1`; הסיסמה תואמת ל־`.env`.

אם נדרש לרענן את סקריפט ה־SQL לאחר שכבר יצרתם את `.env`, בלי להחליף את המפתחות המקומיים:

```powershell
npm run setup:local -- --refresh-sql
```

אם סיסמת מסד הנתונים נחשפה, צרו סיסמה חדשה ועדכנו גם את סקריפט ה־SQL. הריצו:

```powershell
npm run setup:local -- --refresh-sql --rotate-password
```

לאחר מכן הריצו שוב את `database/local-setup.sql` מתוך חיבור מנהל קיים ב־MySQL Workbench, לפני בדיקת ההתחברות של משתמש האפליקציה.

הקבצים `.env` ו־`database/local-setup.sql` מכילים סודות, נוצרים מקומית ומוחרגים מ־Git. אין לשתף אותם. שמרו גיבוי בטוח של `ENCRYPTION_KEY`; בלעדיו לא ניתן לפענח מפתחות API שנשמרו.

### אתחול והפעלה

```powershell
npm run admin:create:local
npm run dev
```

`npm run admin:create:local` מריץ מיגרציות ויוצר את חשבון האדמין הראשון, עם סיסמה אקראית שנשמרת בקובץ המקומי `.initial-admin.txt`. אם רוצים לבחור שם, אימייל וסיסמה בעצמכם, הריצו במקום זאת `npm run admin:create` בטרמינל אינטראקטיבי. הפעלת השרת מוודאת חיבור למסד ומריצה מיגרציות שטרם יושמו לפני קבלת בקשות.

פתחו את כתובת Vite שמוצגת במסוף, בדרך כלל `http://localhost:5173` או `http://localhost:5174` אם הפורט הראשון תפוס. השרת זמין ב־`http://localhost:3001`. נקודת הקצה `GET /api/health` בודקת את זמינות MySQL.

השרת מאשר בקשות רק ממקורות שמוגדרים ב־`CLIENT_ORIGIN`. אפשר להגדיר כמה מקורות מופרדים בפסיקים; ב־localhost שני שמות ה־loopback מותרים אוטומטית. בפריסה יש להגדיר את המקור המדויק של ממשק המשתמש (HTTPS), למשל `CLIENT_ORIGIN=https://app.example.com`, ולהפעיל מחדש את השרת.

### תכונות

- **מורה:** ניהול תלמידים, שפה, רמה, אזור זמן, שעת יצירה, מילים שנלמדו, צפייה בסיפורים ויצירה ידנית.
- **מנהל:** יצירה והשבתה של חשבונות מורים, תמונת מצב ויומן פעילות.
- **ספקי AI:** חיבור לכל API תואם OpenAI Chat Completions, שמירת מפתח מוצפנת ב־AES-256-GCM, עריכת פרומפט ובדיקת חיבור. כתובת API מרוחקת חייבת להשתמש ב־HTTPS.
- **תזמון:** בדיקה מחזורית לפי אזור הזמן המקומי של התלמיד; תור יצירה נשמר ב־MySQL עם אילוץ ייחודי למניעת כפילות למועד; עד שלושה ניסיונות יצירה עם השהיה ותיעוד.
- **אבטחה:** אין הרשמה ציבורית; הסיסמאות נשמרות בגיבוב scrypt; ההתחברות משתמשת בעוגיית HttpOnly חתומה; הרשאות המורה מוגבלות לתלמידים שבבעלותו. מחיקת תלמיד מעבירה אותו לארכיון ושומרת את הסיפורים.

בשלב הנוכחי אין שליחת WhatsApp/SMS, תשלומים או אפליקציה למובייל.
